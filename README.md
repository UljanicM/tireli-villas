# Tireli Villas

One-page website for Tireli Villas, private villas and apartments in Istria.
Plain HTML, CSS and JavaScript, no build step.

- `v1-klasicna/` — the site (open `v1-klasicna/index.html`)
- `images/` — villa photos and the Instagram glyph

Languages: Croatian, English, German (`?lang=en`, `?lang=de`).
